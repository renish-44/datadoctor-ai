## 8. UI States Summary

### 8.1 File Upload Component States
| State | Visual | Trigger |
|-------|--------|---------|
| **Idle** | Dashed border, upload icon, text | Initial state |
| **Dragging** | Blue border, blue background | File dragged over zone |
| **Uploading** | Spinner, progress bar | File being uploaded |
| **Success** | Green checkmark, file info | Upload complete |
| **Error** | Red X, error message | Upload failed |
| **Disabled** | Grayed out, no interaction | During upload |

### 8.2 Loading States
| Component | State | Visual |
|-----------|-------|--------|
| Page load | Skeleton | Gray placeholder boxes |
| Button | Spinner | Animated spinner icon |
| Data fetch | Full page | Centered spinner |
| Table | Row shimmer | Animated gray rows |

### 8.3 Toast Notifications
| Type | Color | Icon | Duration |
|------|-------|------|----------|
| Success | Green | ✓ | 3 seconds |
| Error | Red | ✗ | 5 seconds |
| Warning | Amber | ⚠ | 4 seconds |
| Info | Blue | ℹ | 3 seconds |

## 10. Color System

| Purpose | Color | Usage |
|---------|-------|-------|
| Primary | Blue (#3b82f6) | Buttons, links, active states |
| Success | Green (#22c55e) | Success messages, completed |
| Warning | Amber (#f59e0b) | Warnings, pending states |
| Error | Red (#ef4444) | Errors, delete actions |
| Neutral | Gray (#6b7280) | Text, borders, backgrounds |
| Background | Gray-50 (#f9fafb) | Page background |
| Card | White (#ffffff) | Card backgrounds |
